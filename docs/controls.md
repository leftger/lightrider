# Controls & Keybindings Cheat Sheet

Complete keybindings and input mappings for **LIGHTRIDER**.

---

## Main Menu

* `W` / `Up` or `S` / `Down` → Select menu option (Launch Grid, Ride the Grid, Settings, Controls, Exit)
* `Enter` / `Space` → Confirm selection
* `Esc` / `Backspace` → Back to main menu (from Settings / Controls)
* `A` / `D` or `Left` / `Right` → Adjust options in Settings (toggle bloom, scanlines, audio, adjust volume)
* **Mouse Hover / Click** → Select and activate any menu button

---

## 3D Explorer Mode

### Camera
* **Right-click + drag** → Rotate orbit camera
* **Scroll wheel** → Zoom in / out

### Navigation
* `h` / `Left` → Move selection left
* `j` / `Down` → Move selection down
* `k` / `Up` → Move selection up
* `l` / `Right` → Move selection right
* `o` or `Enter` → Open selected directory / open file in default OS application
* `r` → Reload current directory
* `f` → Reveal selected item in native file manager (Finder / Explorer / Nautilus)
* `u` or `-` → Navigate to parent directory
* `/` → Navigate to filesystem root
* `Home` → Jump to user home directory
* `Backspace` / `Esc` → Step back in navigation history
* `M` → Transition into **Lightcycle Mode**

### Mouse Interaction
* **Hover** → Highlight block
* **Click** → Select block
* **Double Click** (or click selected block) → Enter directory or launch file
* **Click Breadcrumb** → Jump directly to that ancestor path

### UI & Display
* `.` → Toggle hidden files visibility
* `Tab` → Toggle filename labels
* `P` / `Esc` → Pause menu (minigame warper and settings)

---

## Lightcycle Mode

* `A` / `Left` → Queue left turn (executes at the next cell boundary)
* `D` / `Right` → Queue right turn
* **Right-click + drag** → Free look around the cycle (springs back on release)
* `R` → Restart run in the current directory
* `M` → Satellite zoom-out back to Explorer mode
* `u` / `-` → Ride or jump to parent directory
* `Shift` (in minigames) → Engage **Bullet Time** (slows action to 40%)

## Audio Controls

* `N` → Toggle music playback
* `[` → Decrease volume
* `]` → Increase volume
